Use uv to install dependencies. Before committing, run `uv run ruff format .` and `uv run ruff check .`. Add or update tests that cover the affected code paths, and run them with `uv run pytest`. When opening a PR, include user-facing usage examples in the PR description and keep the description up to date with the latest changes. If `pyproject.toml` depends on pydantic, prefer `BaseModel` over `dict` or `dataclass`. Use `python_dotenv` and `load_env()` for environment variables. Keep diffs pure: change only lines directly related to the task; do not opportunistically refactor, extract constants, or edit unrelated nearby code. Always ship the smallest, most reviewable diff. When you find a defect outside the change scope or unrelated to the current task, do not fix it—report it and explain why. Unless the task is a refactor, prefer edge-on integration over invasive changes to the core.
