Use uv to install dependencies. Before committing, run `uv run ruff format .` and `uv run ruff check .`. Add or update tests that cover the affected code paths, and run them with `uv run pytest`. Never commit on `main` (or `master`); always create and switch to a new branch first. When opening a PR, include user-facing usage examples in the PR description and keep the description up to date with the latest changes.
